# 찬양 PPT 메이커

예배 찬양용 가사를 붙여넣으면 **다크 배경 + 흰 글씨** 슬라이드 PPT를 만들어 주는 웹 앱입니다.

## 기능

- 곡 제목 + 가사 붙여넣기
- 기본 **2줄**씩 자동 분할 (3·4줄도 선택 가능)
- 미리보기에서 **줄 수 직접 편집** (2줄 ↔ 3줄 등)
- **드래그 앤 드롭**으로 슬라이드 순서 변경
- **Ctrl/⌘+C·V·X** 슬라이드 복사·붙여넣기·잘라내기 (글자 선택 시엔 일반 텍스트)
- **Ctrl+Enter / ⌘Enter** 로 커서 위치에서 새 슬라이드
- 맨 앞에서 **Backspace** 하면 앞 슬라이드와 합침 (내용 지우면 슬라이드 제거)
- 되돌리기·다시실행
- `1절`, `후렴` 같은 구간 라벨 인식
- 제목 슬라이드 포함 여부 선택
- `.pptx` 바로 다운로드
- PPT **섹션**: 곡마다 곡 제목 하나 (절 단위 구분 없음)
- **곡 진행**(웹): 구간 가사는 한 번만 · 반복 순서는 앱 상단에 표시

## 사용법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 이 열리면:

1. 제목 입력
2. 가사 붙여넣기
3. **슬라이드 만들기**
4. 필요하면 각 슬라이드 가사 수정 (줄바꿈 = 줄 수)
5. **PPT 다운로드**

### 가사 입력 예시

```text
1절
주 예수 이름 높여
우리 모두 찬양해
그 사랑 영원히
우리 안에 흐르네

후렴
할렐루야 할렐루야
주께 영광 돌리세
```

- 빈 줄로 구간을 나눌 수 있습니다.
- `1절`, `2절`, `후렴`, `브릿지` 등은 슬라이드 상단 라벨로 들어갑니다.
- **곡 진행:** 처음에 `1절`·`2절`·`후렴` 가사를 한 번씩 넣고, 뒤에 `1절` / `후렴` 라벨만 이어서 쓰면 가사 슬라이드는 늘지 않고 앱 상단에 진행 순서가 표시됩니다.
- 3줄이 필요한 슬라이드는 미리보기에서 줄을 추가하거나 **다음과 합치기**를 쓰면 됩니다.
